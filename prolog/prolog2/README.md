## [sort.pl](https://github.com/wadehuber/codeexamples/blob/master/prolog/prolog2/sort.pl)

Two sorting approaches in Prolog: permutation sort (declarative but very inefficient - generate a permutation, then check whether it is sorted) and merge sort (a more practical recursive algorithm - split the list, sort each half, then merge the sorted halves).  Comparing the two is a good illustration of how backtracking-based "generate and test" solutions differ from conventional recursive algorithms.
