## [alloc2darr.c](https://github.com/wadehuber/codeexamples/blob/master/c/c6/alloc2darr.c)

Example of dynamically allocating a two-dimensional array: first allocate an array of row pointers with malloc, then allocate an array of integers for each row.  The example fills the array using array indexing, prints it using pointer arithmetic, and frees each row before freeing the array of pointers.
